# راهنمای استقرار رز هاب روی سرور (پورت 8082)

**سرور:** ویندوز سرور — IP استاتیک `130.185.73.157`
**پورت اجرا:** `8082` (در لیست پورت‌های اشغالی سرور آزاد است)
**نشانی نهایی برنامه:** http://130.185.73.157:8082

---

## ۱. پیش‌نیازها

| پیش‌نیاز | حداقل نسخه | وضعیت معمول سرور |
|---|---|---|
| Node.js | 20.9 | اسکریپت خودش نصب می‌کند |
| Git | هر نسخه | اسکریپت خودش نصب می‌کند |
| دسترسی Administrator | — | برای نصب و باز کردن فایروال لازم است |
| اینترنت | — | برای npm install و کلون از GitHub |

> پورت 8082 روی سرور شما آزاد است (پورت‌های اشغالی: 80، 3003، 3005، 3010، 3389، 8085، 8090 و پورت‌های سیستمی ویندوز). اسکریپت از Caddy پورت 80 و Nginx پورت 8085 استفاده‌ای نمی‌کند و تداخلی با آن‌ها ندارد.

## ۲. نصب (یک‌بار)

روی سرور با RDP وارد شوید و **PowerShell را با دسترسی Administrator** باز کنید:

```powershell
# ۱) دانلود اسکریپت استقرار از ریپو
Invoke-WebRequest -Uri "https://raw.githubusercontent.com/sjalilvand/sso_rose/main/deploy-rose-hub.ps1" -OutFile "C:\deploy-rose-hub.ps1"

# ۲) اجرای نصب
powershell -ExecutionPolicy Bypass -File "C:\deploy-rose-hub.ps1"
```

اسکریپت به‌ترتیب این کارها را انجام می‌دهد:

1. بررسی/نصب Node.js 20.9+ (winget یا MSI)
2. بررسی/نصب Git
3. کلون پروژه از GitHub به `C:\RoseHub` (با توکن ذخیره‌شده در اسکریپت)
4. تنظیم `.env` با مسیر نسبی دیتابیس
5. `npm install` + تولید کلاینت Prisma + همگام‌سازی اسکیما
6. ساخت نسخه production (`next build`)
7. باز کردن پورت 8082 در فایروال ویندوز
8. اجرای برنامه با PM2 روی پورت 8082 + ثبت شروع خودکار
9. تست سلامت (`/login` باید 200 برگرداند)

مدت کل نصب: حدود ۵ تا ۱۵ دقیقه (بسته به سرعت اینترنت سرور).

## ۳. به‌روزرسانی (هر بار که ریپو تغییر کرد)

همان اسکریپت را دوباره اجرا کنید — خودش تشخیص می‌دهد و به‌جای نصب، به‌روزرسانی می‌کند:

```powershell
powershell -ExecutionPolicy Bypass -File "C:\deploy-rose-hub.ps1"
```

در حالت به‌روزرسانی:
- برنامه متوقف می‌شود
- از دیتابیس زنده پشتیبان گرفته می‌شود (`db\custom-backup-<تاریخ>.db`)
- سورس از GitHub به‌روز می‌شود
- دیتابیس زنده برگردانده شده و اسکیما در صورت تغییر همگام می‌شود
- بیلد جدید ساخته و برنامه مجدد اجرا می‌شود

## ۴. دستورات مدیریتی روزمره

```powershell
pm2 status              # وضعیت برنامه
pm2 logs rose-hub       # لاگ زنده
pm2 restart rose-hub    # شروع مجدد
pm2 stop rose-hub       # توقف
pm2 monit               # مانیتور منابع
```

## ۵. شروع خودکار پس از ری‌استارت سرور

اسکریپت `pm2-startup` را ثبت می‌کند: پس از هر ری‌استارت ویندوز، با **اولین ورود کاربر (RDP)** برنامه به‌طور خودکار بالا می‌آید (کافی است یک‌بار وارد سرور شوید).

اگر می‌خواهید حتی بدون ورود کاربر هم بالا بیاید (اختیاری):

```powershell
# یک‌بار با دسترسی Administrator، از داخل همان حسابی که نصب را انجام داده:
pm2 save
# سپس در Task Scheduler یک Task با تریگر On start بسازید که این دستور را اجرا کند:
#   C:\Users\<user>\AppData\Roaming\npm\pm2.cmd resurrect
```

## ۶. عیب‌یابی

| مشکل | بررسی / راه‌حل |
|---|---|
| صفحه باز نمی‌شود | `pm2 status` → آیا online است؟ `pm2 logs rose-hub` |
| از بیرون باز نمی‌شود ولی لوکال بله | فایروال: `netsh advfirewall firewall show rule name="Rose Hub 8082"` |
| پورت اشغال بود | `netstat -ano \| findstr :8082` → PID را ببینید؛ یا با پورت دیگر نصب: `-Port 8086` |
| خطای Node قدیمی | `node -v` باید 20.9+ باشد؛ دستی نصب کنید و اسکریپت را دوباره اجرا کنید |
| خطای دیتابیس | فایل `C:\RoseHub\db\custom.db` موجود است؟ `.env` باید `DATABASE_URL=file:../db/custom.db` باشد |
| خطای npm install | پروکسی/اینترنت سرور را چک کنید؛ `npm cache clean --force` و تلاش مجدد |

## ۸. (اختیاری) اتصال دامنه از طریق Caddy موجود

اگر بعداً خواستید برنامه را پشت دامنه بیاورید (به‌جای IP:پورت)، سرور شما Caddy روی پورت 80 دارد. کافی است در `Caddyfile` این بلوک را اضافه کنید:

```caddy
sso.your-domain.ir {
    reverse_proxy 127.0.0.1:8082
}
```

سپس `caddy reload`. در این حالت حتی می‌توانید پورت 8082 را در فایروال ببندید و همه‌چیز پشت دامنه با HTTPS برود.
