# رز هاب | Rose Hub

**درگاه یکپارچه مدیریت، ارتباطات و همکاری مجموعه کلینیک رز سفید**

نسخه ۱.۰ — پیاده‌سازی اجرایی سند «طراحی و پیاده‌سازی سامانه ورود یکپارچه و پنل مدیریت کلینیک رز سفید»

---

## معرفی

رز هاب محیط واحد، زیبا و امن برای دسترسی به سامانه‌های مجموعه رز سفید و مدیریت فعالیت‌های روزانه است. کاربران با **یک حساب کاربری و یک‌بار ورود (SSO)** به سامانه‌هایی که مجوز آن‌ها را دارند دسترسی پیدا می‌کنند و مدیران و کارکنان اطلاعیه‌ها، پیام‌ها، وظایف، تقویم شمسی، گزارش‌ها و یادداشت‌های خود را در یک پنل مرکزی مدیریت می‌کنند.

> **اصل مهم سند:** یک‌بار ورود به معنای دسترسی به همه سایت‌ها نیست؛ مجوز استفاده از هر سامانه جداگانه تعیین می‌شود و کنترل دسترسی سمت سرور انجام می‌گردد.

## امکانات پیاده‌سازی‌شده

| بخش | شرح |
|---|---|
| ورود یکپارچه (SSO) | ورود با یک حساب، صدور توکن موقت (۵ دقیقه)، ثبت رویداد ورود، بازگرداندن کاربر به سامانه مقصد |
| احراز هویت دومرحله‌ای | جریان OTP آماده (در این نسخه حالت نمایشی) |
| مدیریت نشست‌ها | فهرست دستگاه‌های فعال، خروج یکپارچه از هر دستگاه |
| مدیریت کاربران | تعریف، ویرایش، تعلیق، غیرفعال‌سازی، بازنشانی رمز، تعیین مجوز هر سامانه به‌صورت جداگانه |
| نقش‌ها | مدیر کل، مدیر واحد، درمانگر/کارشناس، پذیرش و پشتیبانی، مدرس، کاربر بیرونی |
| اطلاعیه‌ها | سطوح اهمیت (عادی/مهم/فوری)، مخاطبان (همه/واحد/نقش/افراد)، تأیید مطالعه، گزارش مشاهده و تأیید، سنجاق و انقضا |
| وظایف | تعریف و واگذاری، اولویت، مهلت، وضعیت‌ها، گفتگوی وظیفه، **فهرست + برد کانبان**، وظایف عقب‌افتاده |
| تقویم شمسی | نمایش ماهانه با تعطیلات رسمی و جمعه‌ها، ثبت رویداد (جلسه/کلاس/مهلت/رویداد)، برنامه روز |
| یادداشت‌ها | شخصی (محرمانه — حتی برای مدیر) و مشترک، برچسب، جستجو، رنگ‌بندی |
| گفتگوها | پیام خصوصی، گروه کاری، کانال اطلاع‌رسانی، شمارش خوانده‌نشده |
| گزارش‌ها | وضعیت وظایف، ترکیب کاربران، نرخ تأیید اطلاعیه، خروجی CSV/Excel، تفکیک گزارش مدیریتی از داده بالینی |
| جستجوی سراسری | با رعایت سطح دسترسی (Ctrl+K) |
| گزارش فعالیت‌ها (Audit) | ثبت ورود، تغییر دسترسی، عملیات حساس — ویژه مدیر کل |
| رابط کاربری | فارسی راست‌به‌چپ، فونت وزیرمتن، پالت سفید/رز ملایم/سبز یشمی، حالت روشن و تاریک، واکنش‌گرا برای موبایل و رایانه |

## فناوری

- **Next.js 16** (App Router) + TypeScript
- **Tailwind CSS 4** + shadcn/ui + Lucide Icons
- **Prisma ORM** + SQLite
- احراز هویت: JWT (کتابخانه `jose`) در کوکی HttpOnly + جدول Session برای مدیریت نشست‌ها
- هش رمز عبور: scrypt (کتابخانه استاندارد Node)
- فونت: وزیرمتن (Vazirmatn)
- تقویم شمسی: پیاده‌سازی الگوریتم استاندارد جلالی (`src/lib/jalali.ts`)

## اجرا (توسعه محلی)

```bash
# نصب وابستگی‌ها
npm install

# ایجاد پایگاه داده (فایل db/custom.db آماده و seed شده در ریپو موجود است)
npm run db:push

# اجرای سرور توسعه
npm run dev
```

سپس `http://localhost:3000` را باز کنید.

### استقرار روی ویندوز سرور (Production — پورت 8082)

برای نصب کامل روی Windows Server با پورت **8082**، اجرای دائمی با PM2،
نصب خودکار Node.js/Git، باز کردن فایروال و به‌روزرسانی با پشتیبان‌گیری دیتابیس:

```powershell
# روی سرور (PowerShell با دسترسی Administrator):
[Net.ServicePointManager]::SecurityProtocol='Tls12'
irm https://raw.githubusercontent.com/sjalilvand/sso_rose/main/deploy-rose-hub.ps1 -OutFile "$env:TEMP\deploy-rose-hub.ps1"
powershell -ExecutionPolicy Bypass -File "$env:TEMP\deploy-rose-hub.ps1"
```

راهنمای کامل: [`docs/deploy-8082-fa.md`](docs/deploy-8082-fa.md) — مدیریت روزانه با دستورات `pm2 status`، `pm2 logs rose-hub`، `pm2 restart rose-hub`.

## امنیت و محرمانگی (مطابق بند ۷ سند)

- ارتباطات HTTPS و کوکی HttpOnly/SameSite
- عدم اشتراک رمز عبور با سامانه‌های دیگر — فقط توکن موقت امضاشده
- کنترل دسترسی سمت سرور در همه APIها (نه فقط مخفی‌کردن دکمه‌ها)
- ثبت رویدادهای حساس (ورود، تغییر دسترسی، حذف اطلاعیه، ورود یکپارچه)
- یادداشت شخصی فقط برای نویسنده؛ اطلاعات بالینی از گزارش‌های عمومی تفکیک شده است
- محدودسازی رمز (حداقل ۸ نویسه) و پایه پشتیبانی از 2FA
