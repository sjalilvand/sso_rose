## نکات

- وابستگی جدید رز هاب: `leaflet` (+ `@types/leaflet`) — نقشهٔ OSM بدون نیاز به کلید API.
- seed مراکز فقط وقتی جدول خالی است ثبت می‌کند (idempotent)؛ همگام‌سازی از تکنورز رکوردهای هم‌کد را بروز می‌کند و رکوردهای تازه (RD-*) می‌سازد.
- ساختار فایل اکسل گزارش: ۱۲ ستون پایه + بلوک‌های ۵ستونی خدمت + ۴ ستون جمع؛ ماه/سال از نام فایل (مثال «خدمات آزاد شهریور 1405 کلی.xlsx»).
- تست‌های E2E این فاز: `bash scripts/e2e-test.sh` (۱۱ گروه تست — همه سبز روی سندباکس).
